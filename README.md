# Aria — Sonos専用ミュージックプレイヤー（iOS）

純正Sonosアプリの「設定・アップデート」以外の部分、つまり**音楽再生だけ**に特化したiPhoneアプリです。
UIはダークモードの Apple Music に近い黒基調で、基本色にやわらかいラベンダー（#B4A7F5）を使っています。同じWi-Fi上のSonosスピーカーをローカルで直接操作します（クラウド経由ではありません）。

> Sonos社とは無関係の非公式アプリです。ソフトウェアアップデート、初期設定、音楽サービスの追加は純正のSonosアプリで行ってください。

## 機能

| 機能 | 内容 |
| --- | --- |
| 基本操作 | 再生 / 一時停止 / 曲送り・戻し / シーク / シャッフル / リピート / ミュート / スリープタイマー / クロスフェード |
| デザイン | 大きな見出しと横スクロールの棚、すりガラスのミニプレイヤーとタブ、ズームで開く再生画面、アートワークの色で動くメッシュグラデーション背景、一時停止でアートワークが縮む演出、相対ドラッグのシークバー・音量バー。アートワークがない項目は名前から色と模様を作る生成カバーで表示 |
| リアルタイム歌詞 | [Better Lyrics API](https://docs.betterlyrics.org) の**単語（音節）単位**の同期歌詞を優先し、見つからなければ [LRCLIB](https://lrclib.net) の行単位の歌詞を表示。歌っている単語が順に光るカラオケ風表示、デュエットの右寄せ、バックコーラス、現在行の強調とほかの行のぼかし、自動スクロール、間奏の「•••」、行タップでジャンプ、タイミング補正（Sonos の再生位置の遅れを見込んで常に 0.6 秒早めた位置を 0.0 秒としています） |
| 音源品質の表示 | 純正Sonosアプリと同じく、シークバーの下に「Lossless」「Hi-Res Lossless」「Dolby Atmos」「Dolby Digital」などのバッジ。タップで詳細と情報源を表示 |
| サウンド設定 | スピーカーごとに EQ（低音・高音 -10〜+10、ラウドネス）、ステレオバランス、スピーチエンハンスメント・ナイトサウンド（サウンドバーなどホームシアター機）、ハイトオーディオ（Arc / Arc Ultra / Era 300 / Beam 第2世代）。対応していない項目は表示しません。設定 > サウンド、スピーカー選択画面、再生画面の「…」メニューから開けます |
| 2本指の回転で音量 | 画面のどこでも、つまみを回すように2本指でひねると音量が変わります（時計回りで上がる）。中央に音量ダイヤルが表示され、1段ごとに触覚フィードバックがあります。設定で感度変更・オフにできます |
| キュー | 表示、タップで再生、スワイプで削除、並べ替え、全消去、「次に再生」「最後に追加」 |
| スピーカー / グループ | ルームの切り替え、グループへの追加・解除、グループ音量と各ルームの音量 |
| 音楽サービスの併用 | Apple Music・Spotify・Amazon Music を切り替えて使えます。ホームと検索の上部のチップでサービスを選ぶと、そのサービスのお気に入り・棚・検索結果だけを表示します（「すべて」でまとめて表示）。再生中の曲やお気に入りには、どのサービスのものかを色付きのラベルで表示します |
| ブラウズ | Sonosお気に入り、Sonosプレイリスト、ミュージックライブラリ（NAS等）、Apple Musicの検索・おすすめ・最近再生した項目・アルバム・プレイリスト・アーティスト、Spotifyの検索・最近再生した項目・保存したアルバム・プレイリスト・アーティスト |
| リンクから再生 | Apple Music・Spotify・Amazon Music の共有リンク（「共有 > リンクをコピー」）を貼り付けて、再生・次に再生・最後に追加ができます |

### 音源品質の判定方法

純正Sonosアプリの再生画面には「Lossless」「Dolby Atmos」が表示されるので、スピーカーか音楽サービスのどこかにこの情報はあります。ただ、Aria が使っている従来の UPnP API（ポート 1400）では、いまのところ該当する項目を確認できていません（純正アプリはポート 1443 の新しい API を使っていると推測されますが、未調査です）。そのため現状は次の順で判定しています。

1. **テレビ（HDMI / 光）入力**: サウンドバーの `HTAudioIn` から Dolby Atmos / Dolby Digital Plus / マルチチャンネル PCM などを判定（実際の入力形式です）
2. **Sonosが受信しているストリームの情報**: トラックの `protocolInfo`（MIMEタイプ）、ビット深度、サンプルレート、チャンネル数、URI から FLAC / ALAC などのロスレスやハイレゾを判定
3. **Apple Musicのカタログ情報**: 再生中の曲が Apple Music の場合、Apple Music API の `audioTraits` からその曲が対応する形式（Dolby Atmos / Lossless / Hi-Res Lossless）を取得。スピーカーが Dolby Atmos に対応しているか（Arc / Arc Ultra / Era 300 / Beam 第2世代）も考慮します

3のカタログ由来のバッジは右上に小さな点が付き、詳細画面に「Sonosが実際に受信している形式とは異なる場合があります」と表示されます。

## 動作環境

- iOS 18.0 以降
- Xcode 16 以降（Xcode 26 推奨）
- Sonos S2 システムのスピーカー（iPhone と同じネットワーク上）

## ビルド方法

1. `Aria.xcodeproj` を Xcode で開く
   - 開けない場合は [XcodeGen](https://github.com/yonaskolb/XcodeGen) で `xcodegen generate` を実行してプロジェクトを作り直してください（`project.yml` 同梱）
2. ターゲット **Aria** の *Signing & Capabilities* で自分の Team を選び、Bundle Identifier を `com.example.aria` から自分のものに変更
3. **Apple Musicを使う場合**: [Apple Developer の Identifiers](https://developer.apple.com/account/resources/identifiers/list) で上記の Bundle ID を選び、*App Services* タブの **MusicKit** にチェックを入れて保存
   （これがないと検索・おすすめ・カタログの音質情報が取得できません。Sonosのお気に入り・プレイリスト・キュー操作は MusicKit なしで使えます）
4. 実機を選んで Run
5. 初回起動時に「ローカルネットワーク」へのアクセスを**許可**してください（スピーカーの検出に必要です）

スピーカーが見つからない場合は、ホーム画面または設定画面からスピーカーの IP アドレスを直接入力できます（Sonosアプリの *設定 > システム > このシステムについて* で確認できます）。

## 音楽サービスについて

どのサービスも、**再生は Sonos に登録されているアカウント**で行われます（純正Sonosアプリで各サービスを追加しておいてください）。アプリ内のログインは「何を再生するか」を探すためだけに使います。

| サービス | 検索・ホームの棚 | 再生 |
| --- | --- | --- |
| Apple Music | MusicKit（上記の MusicKit の有効化が必要）。使えない場合も曲・アルバム・アーティストは簡易検索で探せます | 検索結果・ライブラリ・お気に入り・リンク |
| Spotify | Spotify Web API（下記の Client ID の設定が必要） | 検索結果・お気に入り・リンク |
| Amazon Music | なし（公開された検索APIがないため） | お気に入り・リンク |

### Spotify の設定

1. [Spotify for Developers のダッシュボード](https://developer.spotify.com/dashboard)でアプリを作成
2. Redirect URI に `aria-sonos://spotify-callback` を登録し、「Web API」にチェック
3. 表示された **Client ID** を、アプリの 設定 > 音楽サービス > Spotify に入力して「Spotifyにログイン」

開発モードのアプリは、ダッシュボードの *User Management* に登録したアカウントしかログインできません。また Spotify 側の方針で、開発モードでは利用できる API が制限されることがあります。共有リンクからの再生は、この設定なしで使えます。

### アカウント番号

Sonos は同じサービスの複数アカウントを番号（`sn=`）で区別します。アプリはお気に入り・キュー・再生中の曲からサービスごとに番号を自動検出します。再生時に「アクセスを拒否」などと表示される場合は、設定 > 音楽サービス > 各サービス の「手動指定」で 1〜5 を順に試してください。各サービスの曲を1つ Sonos のお気に入りに登録しておくと、自動検出されやすくなります。

### Apple Music の検索とライブラリ

| 機能 | 必要なもの |
| --- | --- |
| 曲・アルバム・アーティストの検索 | なし（MusicKit が使えないときは Apple の公開検索API〈iTunes Search API〉で検索します） |
| プレイリストの検索、おすすめ、最近再生した項目、音質情報 | Apple Music API（開発者トークン） |
| 自分のライブラリのプレイリスト・アルバム（ホームとライブラリ画面に表示） | Apple Music API（開発者トークン）＋ iPhone で Apple Music にサインインし「ライブラリを同期」がオン |

Apple Music API の開発者トークンは、**自分のチーム（Apple Developer Program）で署名し、その Bundle ID で MusicKit を有効にしたアプリ**にだけ自動で発行されます（上記「ビルド方法」の 2〜3）。チームを選ばずにビルドした場合や、MusicKit を有効にしていない場合は「開発者トークンを取得できません」と表示されます。シミュレータでは Apple Music にサインインできないため、ライブラリは実機でのみ読み込めます。状態は 設定 > 音楽サービス > Apple Music で確認できます。

**Apple Developer Program に加入しない場合**も、曲・アルバム・アーティストの簡易検索と再生、Sonos のお気に入りからの再生は使えます。自分のプレイリストは、純正の Sonos アプリで「お気に入り」に追加すると、ホームの「お気に入り」とライブラリの「Sonosお気に入り」から再生できます（ライブラリのプレイリストも再生できます）。無料の Apple ID でも Xcode から自分の iPhone にインストールできますが、7日ごとに入れ直しが必要です。

## Apple Music の再生について

Apple Music の曲・アルバム・プレイリストは、**Sonos に登録されている Apple Music アカウント**で再生されます（純正Sonosアプリで Apple Music を追加しておいてください）。

再生時に「アクセスを拒否」と表示される場合は、Sonos 上のアカウント番号が自動検出できていない可能性があります。設定 > Apple Music の「手動指定」で 1〜5 を順に試してください。Sonosのお気に入りに Apple Music の曲を1つ登録しておくと、自動検出されやすくなります。

カタログ上のアルバム・プレイリストに加えて、自分のライブラリのプレイリスト（ID が `p.` で始まるもの）も再生できます。ライブラリにだけあるアルバム（ID が `l.` で始まるもの）は再生できません。

## 仕組み

- **検出**: Bonjour（`_sonos._tcp`）。SSDP のマルチキャストは Apple の特別なエンタイトルメントが必要なため使っていません
- **操作**: 各スピーカーのポート 1400 の UPnP / SOAP API（AVTransport、GroupRenderingControl、RenderingControl、ContentDirectory、ZoneGroupTopology、DeviceProperties）
- **状態の取得**: 1 秒ごとのポーリング。再生位置は端末側で補間し、歌詞の同期精度を上げています
- **音量の回転操作**: アプリのウインドウに `UIRotationGestureRecognizer` を取り付けているため、シートや再生画面の上でも動作します。送信は最新値だけを順に送るため、速く回してもスピーカーに負荷をかけません

```
Aria/
├── App/          エントリーポイント、デッキ（画面切り替え＋ミニプレイヤー）
├── Sonos/        SOAPクライアント、DIDL/XMLパーサー、トポロジー、Bonjour検出、SonosStore（状態と操作）
├── Music/        サービス定義と Sonos 用 URI の組み立て、共有リンクの解析、MusicKit、Spotify Web API
├── Lyrics/       Better Lyrics / LRCLIB クライアント、TTML・LRCパーサー、歌詞の状態
├── Quality/      音源品質の判定
├── Gesture/      2本指回転による音量操作と音量ダイヤル表示
└── UI/           再生画面、歌詞、キュー、スピーカー選択、ホーム、ライブラリ、検索、設定
```

## 既知の制限

- Xcode 27.2 でのビルドと、iPhone 12 Pro シミュレータでの表示までは確認済みです。実機での動作は未確認です
- ロック画面・コントロールセンターの再生コントロール、本体の音量ボタンでの Sonos 音量操作は未対応です
- Better Lyrics API はキャッシュ済みの曲だけが API キーなしで取得できます（キーは第三者に配布されていません）。キャッシュにない曲や混雑時（401 / 429 / 5xx）は LRCLIB の行単位の歌詞になります
- 歌詞はコミュニティデータのため、曲によっては見つからない・タイミングがずれることがあります（再生画面の「…」メニューか設定で補正できます）
- Spotify・Amazon Music の再生用 URI は、Sonos コミュニティで知られている形式から組み立てています（形式が合わない場合に備えて複数の候補を順に試します）。まだ実機の Spotify / Amazon Music アカウントでは確認していません
- Amazon Music はアプリ内で検索できません（共有リンクとお気に入りから再生）
- 上記3サービス以外（YouTube Music、Deezer など）は、Sonosのお気に入り・プレイリスト経由で再生できます
